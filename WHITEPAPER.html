📄 Executive Summary

Public blockchain addresses are 42-character hexadecimal strings that are difficult for human eyes to distinguish. While solutions like PFP NFTs and domain services exist, they introduce secondary market speculation, recurring rental fees, and heavy external metadata dependencies.

ColorTag introduces a clean, minimalist visual identity primitive natively deployed on Botchain. It allows any Web3 wallet holder to bind a custom 6-digit hexadecimal color code (#RRGGBB) directly to their address on the blockchain ledger. ColorTag operates with zero centralized servers, zero databases, zero admin backdoors, and zero non-gas fees.

⚠️ 1. Problem Statement

Alphanumeric Cognitive Noise

Users and bots interact with indistinguishable 42-character hashes, dramatically increasing the risk of misdirected transfers and phishing attacks.

Speculative Identity Market

Traditional NFT avatars are treated as volatile investment assets rather than reliable personal signatures, subject to off-chain IPFS link degradation.

Recurring Domain Rents

Decentralized domain registries charge annual renewal fees, resulting in squatted handles and expensive resolver calls.

Web2 Database Enclaves

Most modern dApps store personal customizations in centralized off-chain databases (AWS/Supabase), abandoning cryptographic sovereignty.

🛠️ 3. Smart Contract Specification

The core contract ColorTag.sol is written in Solidity ^0.8.24 and optimized for minimal gas consumption:

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

contract ColorTag {
    mapping(address => string) private _colors;
    mapping(address => bool) private _hasColor;

    event ColorSaved(address indexed user, string color);

    function isValidColor(string memory color) public pure returns (bool) {
        bytes memory b = bytes(color);
        if (b.length != 7 || b[0] != 0x23) return false;
        for (uint256 i = 1; i < 7; i++) {
            bytes1 c = b[i];
            if (!((c >= 0x30 && c <= 0x39) || (c >= 0x61 && c <= 0x66) || (c >= 0x41 && c <= 0x46))) {
                return false;
            }
        }
        return true;
    }

    function setColor(string calldata color) external {
        require(isValidColor(color), "Invalid color format. Expected #RRGGBB");
        _colors[msg.sender] = color;
        _hasColor[msg.sender] = true;
        emit ColorSaved(msg.sender, color);
    }

    function getColor(address user) external view returns (string memory) {
        return _colors[user];
    }

    function hasColor(address user) external view returns (bool) {
        return _hasColor[user];
    }
}
